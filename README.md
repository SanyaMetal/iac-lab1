# Лабораторная работа № 1


Фронтенд: Nginx и статическая HTML-страница.
Бэкенд: HTTP-сервер на Python.


Плейбук Ansible устанавливает Docker и Docker Compose,
получает проект из Git, собирает образы и запускает контейнеры.


Приложение доступно на порту 8080 сервера Ubuntu-Node1.
Бэкенд доступен через маршрут /api/message фронтенда.

Исходники приложения, Dockerfile, Compose и файлы Ansible
хранятся в одном Git-репозитории.
